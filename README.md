# 大肥鱼的QQ机器人服务

把 **QQ 官方机器人**接上一个**自托管控制台**：填凭据 → 连上网关 → 配人格、配模型、装插件，全程在浏览器里点。
**不需要 DeepSeek Harness 也能独立运行**；想接 Harness 继续开发，也有一个专门的页面。

```
QQ 客户端 ⇄ QQ 开放平台 ⇄ WebSocket ⇄ ┌──────────────────────────────┐
                                      │  桥接进程（standalone/）       │
                                      │   · 收消息 / 回消息            │
                                      │   · 每会话上下文               │
                                      │   · 应用人格 / 能力 / 模型      │
                                      └──────────────┬───────────────┘
                                                     │ 文件即接口
                                      ┌──────────────┴───────────────┐
                                      │  runtime/qqbot.config.json    │
                                      │  qqbot-status.json / qqbot.log│
                                      └──────────────┬───────────────┘
                                                     │
                                      ┌──────────────┴───────────────┐
                                      │  控制台（dashboard/，零依赖）  │
                                      │   · 九个页面 + REST API        │
                                      │   · 凭据 / 模型 / 插件 / 日志   │
                                      └──────────────────────────────┘
```

## 三分钟跑起来

```bash
docker run -d --name qqbot --restart always -p 9999:9999 \
  -e TZ=Asia/Shanghai \
  -v qqbot-data:/data/qqbot \
  ghcr.io/fx071002/dsbot_qq:latest
```

浏览器打开 **`http://<你的地址>:9999/`**：

1. **登录**：出厂账号与密码均为 `harness`（登录框下方也写着）。首次登录会**强制**改成你自己的账号密码
   （至少 6 位，且必须同时含大写字母、小写字母和数字），改完自动退出，用新账号重新登录即可。
2. **连接**（左边第一个页面，置顶）：填 QQ 开放平台的 **AppID** 与 **AppSecret**，保存 → 桥接自动重连，
   状态条变成「在线」就能在 QQ 里对话了。
3. **模型**：先在「接入其他模型服务商」里加一个 OpenAI 兼容的服务商（预设里有智谱 / 通义 / Kimi /
   硅基流动 / OpenAI / OpenRouter，也可以自定义接口地址），填 Key、点「拉取模型」，
   再回到上面把**对话模型**选成它。
4. 想让它有人设：**人格** 页；想控制群 @ / 私聊范围与白名单：**机器人** 页；要加自己的指令：**插件** 页。

端口想换成别的：改 `-p` 左边即可，例如 `-p 18000:9999`（容器内固定 9999）。
真要改容器内端口，用 `-e QQBOT_PORT=...` 并同步改 `-p` 右侧。

## 控制台页面

| 页面 | 做什么 |
|---|---|
| **连接**（置顶） | 填 QQ 机器人 AppID / AppSecret，一键测试连通性，看网关状态 |
| 总览 | 运行状态、消息计数、当前人格/能力/模型、重载与清日志 |
| 机器人 | 开关、群 @ / 私聊范围、白名单、回执、入群与加好友欢迎语、分条长度 |
| 人格 | 角色设定（名称/身份/风格/规则），或完全自定义提示词，含预设一键套用 |
| 能力 | 工具、联网、生图（生图可指定服务商、模型、图片公网地址） |
| 模型 | **五类模型的独立选择**（见下）+ 接入其他模型服务商 |
| **知识库** | 上传本地资料（txt/md/csv/ini/json/docx/xlsx/pptx），编排成分类与条目；模型对话时用 `kb_list`/`kb_search`/`kb_read` 直接查，省掉联网搜索的延迟。优先级低于人格设定 |
| Harness 服务 | 把控制台接到一个 DeepSeek Harness（DeepSeek / OpenAI / 自定义），并可选锁定主干模型 |
| 插件 | 安装（内置/本地目录/tar.gz 链接）、启停、编辑提示词、卸载 |
| 日志 | 实时日志、过滤、清空 |

### 五类模型

| 类型 | 用途 | 出厂值 |
|---|---|---|
| 对话模型 | QQ 里的对话 | **空** |
| 语音转文字 | 把语音消息转成文字 | **空** |
| 文字转语音 | 把回复读出来 | **空** |
| 嵌入 | 文本向量化（知识库 / 检索） | **空** |
| 重排序 | 检索结果重排（RAG 质量） | **空** |

**出厂一律留空**，由使用者自己接入服务商与模型；每一类都带一个「测试」按钮，
点下去会发一次**真实的最小请求**并如实回报结果（对话看回复、嵌入看向量维度、重排序看结果条数、
语音合成看返回的音频大小、语音转文字做可达性与模型存在性校验）。详见 [docs/models.md](docs/models.md)。

## 两种运行方式

| | 独立运行（默认） | 作为 Harness 插件 |
|---|---|---|
| 命令 | `./standalone/start.sh` 或直接用镜像 | `./install.sh` 装进 Harness 的 profile |
| 依赖 | **只要 Node.js ≥ 22** | DeepSeek Harness |
| 能力 | 对话、多轮上下文、人格、白名单、插件指令、生图（函数调用） | 额外获得 Harness 的工具链（联网 / 文件 / 命令 / 子代理）与会话审计 |
| 配置 | 同一份 `runtime/qqbot.config.json`、同一个控制台 | 同左 |

想两者都要：先用独立模式跑起来；以后想接 Harness，就到「Harness 服务」页填地址与密钥，
再按 [docs/harness.md](docs/harness.md) 把插件装进 Harness。

## 目录

| 路径 | 作用 |
|---|---|
| `standalone/` | 独立运行入口：网关 + 上下文 + 对话 + 控制通道 + 控制台守护 |
| `dashboard/` | 控制台服务端、前端（`public/`）与内置插件（`builtin-plugins/`） |
| `shared/` | 两端共用的纯模块：运行时 schema、插件格式、生图客户端 |
| `qqbot-core/` | QQ 协议层（OpenAPI 客户端 / 网关客户端 / 状态通道）+ 可选的 Harness 插件 |
| `scripts/` | 启停、改密码、备份、自测、模拟服务商 |
| `docker/` | Harness 模式部署示例 |

## 运行要求

- Node.js ≥ 22（用镜像则无需关心）
- 一个 QQ 开放平台的机器人（AppID + AppSecret），并已开通「群聊 / 单聊」消息能力
