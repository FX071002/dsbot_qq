# 运维与页面说明

## 一、登录与控制台账号

- 出厂账号：**用户名 `harness`，密码 `harness`**（登录框下方有提示）。
- **首次登录后强制改密**：至少 6 位，且必须同时包含大写字母、小写字母和数字；
  用户名也可以一起改。改完**所有会话立即作废**，必须用新账号重新登录，之后才能真正使用控制台。
- 在改密之前，除登录/登出/改密/会话查询以外的所有接口都会返回
  `403 {code:'must_change_credentials'}`——这是服务端强制的，不是前端拦截。
- 忘记密码时（在服务器上执行）：

  ```bash
  node scripts/set-password.sh <用户名> <新密码>      # 同样会注销所有已登录会话
  ```

- 会话是 30 天的 Cookie（`HttpOnly` + `SameSite=Lax`）；密码以 scrypt 加盐哈希存在
  `runtime/dashboard.auth.json`（600），**不存明文**。

## 二、页面逐个说

### 连接（置顶）

- 填 **AppID** 与 **AppSecret**（AppSecret 是密码框，可点眼睛显示）；
- 保存后桥接进程会在几秒内**自动重连**（不用重启任何东西）；
- 「测试连接」会真的去换一次 AccessToken 并取网关地址，成功/失败都原样回报；
- 状态条三态：`未配置` / `连接中` / `在线（机器人名）`。

凭据来源优先级：**控制台这里填的 > 环境变量 > `standalone/config.json`**。

### 总览

运行状态（state/bot/gateway）、消息计数（收到 / 回复 / 失败 / 拒绝）、当前人格与能力开关、
生效模型、已装插件数、在线会话；还有两个操作按钮：重载配置、清空日志。

### 机器人

总开关、群 @ 是否回复、私聊是否回复、用户/群白名单（openid，一行一个）、
"已收到"回执文案、入群欢迎语、加好友欢迎语、回复分条的最大字数与最大条数、是否附带发送者信息。

> 白名单留空 = 不限制。填了就只回应列表里的。

### 人格

名称、身份、风格、规则四段式，或打开"自定义"直接写完整提示词；顶部有预设可一键套用。
插件里配置的 `prompt` 段落会追加在人格之后。

### 能力

- **工具**：是否允许桥接注册工具（Harness 模式下才有意义）；
- **联网**：Harness 模式下是否放行联网类工具；
- **生图**：开关、服务商（硅基流动 / OpenAI / 智谱 / 自定义）、接口地址、Key、模型、尺寸、
  以及**图片公网地址**（当服务商只返回 base64 时，用它拼出 QQ 能拉取的 URL；不填就只能拿到链接文本）。

### 模型

见 [models.md](models.md)。一句话：五类模型各自选服务商与模型，出厂全空，每类都能一键真实测试。

### Harness 服务

见 [harness.md](harness.md)。配置 Harness 的地址与密钥、测试连通性，可选地锁定 Harness 主干模型。

### 插件

安装（内置四个：help / ping / weather / hitokoto；也可从本地目录或 tar.gz 链接装）、
启用停用、编辑提示词、卸载。格式见 [plugin-format.md](plugin-format.md)。
插件里的快捷指令在消息进模型**之前**匹配，命中就直接回复，不消耗模型额度。

### 日志

实时日志（追加式、1 MiB 轮转）、按级别过滤、清空。
排障先看这里：网关关闭码、鉴权失败、模型报错都会写进来。

## 三、状态与日志文件

| 文件 | 内容 |
|---|---|
| `qqbot-status.json` | 当前状态快照（控制台读它），原子写 |
| `qqbot.log` | 追加式日志，1 MiB 轮转 |
| `runtime/qqbot.config.json` | 全部配置（控制台写入，桥接监听变化） |
| `runtime/control.json` → `runtime/control-result.json` | 控制通道：测试、重连、拉取模型等 |
| `runtime/dashboard.auth.json` | 控制台账号（scrypt 哈希 + 会话表，600） |
| `runtime/media/` | 生图落盘的图片（当公网地址配好时） |

## 四、日常运维

```bash
# 看状态
cat qqbot-status.json | head -20

# 跟随日志
tail -f qqbot.log            # 或在控制台「日志」页看

# 重启桥接（独立模式）
pkill -f standalone/server.js && ./standalone/start.sh

# 备份（代码 + 运行时 + 凭据，三个文件 + 校验和）
bash scripts/make-backup.sh
```

## 五、排障

| 现象 | 先查什么 |
|---|---|
| 状态 `unconfigured` | 「连接」页是否填了凭据并保存 |
| 测试连接报 `10004 机器人不存在` | AppID / AppSecret 与开放平台是否一致 |
| 频繁重连 / `4014` | 开放平台是否开通了「群聊 / 单聊」消息能力（intents） |
| QQ 里 @ 了没反应 | 「机器人」页开关与白名单；日志里有没有"未被当前配置接受" |
| 模型报错 | 「模型」页点对应类型的「测试」，看真实报错 |
| 控制台打不开 | 进程是否在跑（`ps`/`docker ps`）、端口是否发布 |
| 改完配置没生效 | 桥接每 700 ms 检查一次配置，通常是 1 秒内生效；没生效看日志有没有 revision 冲突 |
| 想回到出厂状态 | 删掉 `runtime/qqbot.config.json` 与 `runtime/dashboard.auth.json`，重启即可 |
